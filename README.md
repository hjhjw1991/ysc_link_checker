# 影视仓链接检测器 (YSC Link Checker)

一个跨平台（Windows / macOS / Linux / Android Termux）的影视仓/电视盒子资源推送链接检测工具。

## 功能

- 每次运行自动收集最新影视仓配置/直播源链接（内置源 + 自动展开多仓子线路 + GitHub 接口仓库）
- 逐条网络探测可用性：HTTP 状态 + 内容级校验（有效 JSON 配置 / 有效文本列表 / 剔除防爬 HTML 页）
- 只输出探测通过的链接，并保存为 txt 便于复制进影视仓「配置地址」
- 纯 Python 标准库，无需安装任何第三方依赖
- 支持中文域名（punycode）、中文路径自动转义、gh-proxy 镜像重试
- 宽容解析民间配置（// 与 # 注释、尾逗号、字符串内裸换行等）

## 用法

```
python ysc_link_checker.py
```

可选参数：

| 参数 | 说明 |
| --- | --- |
| `--timeout 10` | 单个链接超时秒数（默认 10） |
| `--workers 12` | 并发线程数（默认 12） |
| `--extra URL` | 额外追加检测链接（可多次） |
| `--no-dynamic` | 不展开多仓 / 不抓 GitHub，只检测内置列表 |
| `--out 文件名` | 自定义输出文件名 |

运行结束后生成：`影视仓可用链接_日期_时间.txt`（可直接使用）和 `检测明细_日期_时间.json`（含失败原因）。

## 自定义数据源

编辑脚本中 `SEED_LINKS`（单条源）、`GITHUB_MD_SOURCES`（Markdown 接口大全仓库）、`GITHUB_REPO_SOURCES`（配置文件仓库）三个列表即可增删数据源。
